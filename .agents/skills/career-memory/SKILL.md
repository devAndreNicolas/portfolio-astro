# Career memory

Use this skill when ingesting a CV, portfolio case study, LinkedIn export, project evidence, or a correction from André.

Read `career/profile/master-career.md` first. Add only supported facts with a source path, date, and confidence note. Keep three distinct groups:

- **Evidence-backed claims:** safe to select, translate, and tailor.
- **Positioning themes:** factual synthesis, not a substitute for evidence.
- **Development targets / market signals:** useful for learning plans and job analysis, never presented as experience.

Do not invent or conceal material facts. It is fine to omit irrelevant project business status; it is not fine to state revenue, customers, company ownership, a different school, or an unearned title. For international education, preserve `Tecnólogo em Sistemas para Internet — UNCISAL` and explain the credential in plain English if useful.

When an input conflicts with existing memory, retain both sources and flag the conflict for André instead of guessing. Update the canonical source document, then report the new claims, claims needing evidence, and implications for CV variants.
