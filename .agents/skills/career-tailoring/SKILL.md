# Career tailoring

Read `career/profile/master-career.md`, the target job description, and the requested canonical CV first. Build a requirement-to-evidence table before drafting.

Only select, reorder, condense, or clarify claims supported by the career document. If important evidence is missing, ask one batched set of questions; do not imply experience. Record the job description in `career/jobs/` and write the tailored output under `career/applications/<company>-<role>/`.

Use exact, conventional headings: Summary, Experience, Skills, Education. Maintain the target language. Finish by invoking the `cv-qa` skill.
