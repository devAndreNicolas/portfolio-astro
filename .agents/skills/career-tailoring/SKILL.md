# Career tailoring

Read `career/profile/master-career.md`, the target job description, and the requested canonical CV first. Build a requirement-to-evidence table before drafting. Read `career/market/2026-positioning.md` only to choose emphasis and questions; it never proves a candidate claim.

Only select, reorder, condense, translate, or clarify claims supported by the career document. Translate Brazilian education transparently (for example, retain the official degree and add an explanatory equivalent); do not rename institutions or fabricate revenue, employment, customers, projects, titles, or outcomes. If important evidence is missing, ask one batched set of questions; do not imply experience. Record the job description in `career/jobs/` and write the tailored output under `career/applications/<company>-<role>/`.

Use exact, conventional headings: Summary, Experience, Skills, Education. Maintain the target language. Finish by invoking the `cv-qa` skill.
