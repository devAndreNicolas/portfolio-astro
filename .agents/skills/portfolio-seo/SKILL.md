# Portfolio SEO

Before editing, inspect the relevant content source and its existing metadata. Preserve factual claims and use clear human language rather than keyword stuffing.

Every indexable page needs a specific title, description, canonical URL, Open Graph data, and appropriate structured data. Update sitemap/robots implications when routes change. Make the visible H1 match the page intent. Do not present a public CV as an indexed HTML duplicate of a job-specific resume.

Run `pnpm validate` and report any missing `SITE_URL` configuration.
