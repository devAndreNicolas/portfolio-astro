Desenvolvedor(a) Full Stack (com ênfase em Frontend)

This position is listed on behalf of a partner company, who manages all applications and next steps. Our partner is looking for a Desenvolvedor(a) Full Stack (com ênfase em Frontend) based in Brazil.

We are looking for a creative and experienced Full Stack Developer with a strong focus on frontend development to build and enhance high-performance e-commerce experiences. In this role, you will develop scalable, responsive, and accessible web interfaces using React, Next.js, and TypeScript. You will contribute to the entire development lifecycle, from technical design and implementation to testing, deployment, and continuous optimization. Working closely with product, design, and marketing teams, you will transform business requirements into intuitive digital experiences that improve customer engagement and conversion. You will also contribute to backend integrations, frontend architecture, and reusable component development. The position offers a fully remote work environment, collaborative teams, and opportunities to leverage AI-powered tools to improve engineering productivity.

Accountabilities
Design, develop, and maintain scalable, responsive, and accessible frontend interfaces using React, Next.js, TypeScript, HTML, and modern CSS.
Build and optimize key e-commerce journeys, including storefronts, product discovery, search, product pages, shopping carts, checkout, and customer account areas.
Translate product requirements and design specifications into high-quality user interfaces, ensuring visual consistency and usability across devices and browsers.
Integrate REST and GraphQL APIs with e-commerce platforms, payment providers, and third-party services to deliver seamless digital experiences.
Monitor and improve website performance, Core Web Vitals, technical SEO, accessibility, and overall user experience.
Develop Node.js middleware and supporting services when required to enable frontend functionality and system integrations.
Contribute to frontend architecture decisions, componentization, reusable design systems, and maintainable application structures.
Manage code versioning, participate in code reviews, implement automated tests where appropriate, and follow engineering best practices.
Deploy and validate applications across testing and production environments using CI/CD pipelines, monitoring releases and resolving issues.
Incorporate AI tools into development workflows, including technical specification, code generation and review, testing, and documentation, following established engineering practices.
Maintain clear technical documentation and collaborate with cross-functional teams to deliver solutions aligned with business priorities.
Adapt to changing requirements and priorities in a dynamic retail and e-commerce environment.
Requirements
Solid experience with React, JavaScript, TypeScript, semantic HTML, and modern CSS technologies such as CSS Modules, Styled Components, or Tailwind CSS.
Experience with Next.js, including server-side rendering, static generation, API routes, image optimization, and caching, or a demonstrated ability to learn these capabilities quickly.
Experience integrating REST and GraphQL APIs and working with third-party services.
Knowledge of web performance optimization, Core Web Vitals, technical SEO, accessibility, and responsive design.
Practical experience with Node.js for developing middleware and frontend-supporting services.
Proficiency with Git and GitHub, including branching strategies, pull requests, and code review practices.
Experience with CI/CD pipelines, such as GitHub Actions or equivalent tools, and application deployment across testing and production environments.
Familiarity with AI-assisted software development, including specification-driven development, coding assistants such as Claude and other large language models, AI agents, and MCPs.
Understanding of agile methodologies, such as Scrum or Kanban.
Strong communication, analytical thinking, problem-solving, and collaboration skills, with the ability to work effectively across multidisciplinary teams.

Additional qualifications that would be an advantage:

Experience with automated testing tools such as Jest, React Testing Library, Cypress, or Playwright.
Familiarity with headless frontend architectures and platforms such as Adobe Commerce or Magento.
Experience with Material UI, other design systems, or reusable component library development.
Knowledge of micro-frontends, monorepos, and scalable application architecture.
Familiarity with analytics tools, tag management, and A/B testing for e-commerce.
Additional backend development experience with Node.js and SQL or NoSQL databases.
Knowledge of cloud environments, content delivery networks (CDNs), and web application monitoring.
Previous experience in retail, e-commerce, or omnichannel environments with high traffic volumes and business-critical workflows.
