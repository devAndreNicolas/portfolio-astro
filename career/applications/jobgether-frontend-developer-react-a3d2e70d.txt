Frontend Developer (React)
BrazilSecurity & IT – IT /Full-Time /Remote
	APPLY FOR THIS JOB

This position is listed on behalf of a partner company, who manages all applications and next steps. Our partner is looking for a Frontend Developer (React) based in Brazil.

Join a product-focused development team building innovative web applications that deliver meaningful value to users and businesses. As a Frontend Developer (React), you will contribute to the design, development, and continuous improvement of modern, interactive, and high-performance user interfaces. You will collaborate closely with web developers and technology leadership, balancing ongoing product support with new feature development. This role offers significant autonomy, allowing you to influence technical decisions, shape application architecture, and introduce tools and practices that improve development efficiency. You will work in an environment that values code quality, innovation, and continuous learning. With a strong emphasis on collaboration and ownership, this opportunity offers room to expand your technical expertise while contributing to products with real-world impact.

Accountabilities

Collaborate with the web development team and technology leadership to deliver product features, improvements, and technical solutions, allocating approximately 70% of your time to development and 30% to support activities.

Design, develop, and maintain interactive, responsive, and high-performance web applications using React.

Contribute to selecting and implementing appropriate tools, technologies, frameworks, and development methodologies.

Design and implement scalable, maintainable frontend application architectures aligned with product requirements.

Build efficient user interfaces using React hooks, TypeScript, modern JavaScript, and established frontend development practices.

Manage application state using Redux, Flux, or other appropriate state management approaches.

Develop and optimize CSS, ensuring maintainable styling, efficient rendering, and consistent user experiences across interfaces.

Integrate frontend applications with backend services through REST APIs and apply relevant service-oriented architecture concepts.

Conduct code reviews, maintain high coding standards, and promote best practices across the development team.

Identify and resolve technical issues, optimize application performance, and improve code quality where needed.

Support continuous integration and continuous delivery workflows and contribute to improving development processes.

Collaborate with team members to troubleshoot issues, maintain existing functionality, and deliver new features efficiently.

Requirements:

At least three years of professional experience developing web applications, including a minimum of two years working with React.js.

Strong proficiency in React and experience building interactive, responsive, and performant user interfaces.

Solid understanding of object-oriented programming and functional programming principles and design patterns.

Practical experience with React hooks, TypeScript, and modern frontend application architecture.

Experience with state management libraries and patterns, particularly Redux or Flux.

Strong knowledge of CSS methodologies, styling tools, optimization techniques, and browser rendering behavior.

Proficiency in modern JavaScript, including ES6, ES7, and ES8 standards.

Experience using Git and code collaboration platforms such as GitHub or GitLab.

Understanding of REST APIs and service-oriented architecture concepts.

Familiarity with CI/CD principles, tools, and workflows.

Strong problem-solving and analytical skills, attention to detail, and a commitment to writing clean, maintainable code.

Ability to work independently, collaborate effectively with cross-functional teams, and take ownership of technical decisions.

Nice to have: Experience working on high-traffic or high-load applications.

Nice to have: Familiarity with Node.js and backend development.

Nice to have: Strong knowledge of SOLID principles, software design patterns, and distributed application architecture.

Nice to have: Experience with Docker containers and setting up development environments.

Nice to have: Familiarity with Linux-based operating systems and Bash scripting.

Professional growth: Opportunities to expand your technical skills, explore modern technologies, and develop alongside an experienced product team.
