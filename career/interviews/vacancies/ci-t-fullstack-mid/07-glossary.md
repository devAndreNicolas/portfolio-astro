# Glossário

- **Spring:** ecossistema Java para aplicações e serviços; não apresentar experiência profissional própria sem evidência.
- **SASS:** pré-processador de CSS com variáveis, nesting e organização de estilos.
- **Microfrontend:** composição de partes independentes de uma aplicação frontend.
- **SQL Server:** banco relacional; a experiência comprovada de André é principalmente PostgreSQL.
- **Sonar:** análise automatizada de qualidade e possíveis problemas de código.
- **DAST:** teste dinâmico de segurança de uma aplicação em execução.
- **Scrum:** framework ágil com ciclos, planejamento, revisão e retrospectiva.
