# Glossário

- **SDK:** conjunto de código e interfaces para integrar uma capacidade a outros produtos.
- **Client-side:** código executado no navegador ou dispositivo do usuário.
- **Device intelligence:** sinais sobre dispositivo e ambiente usados para avaliar risco.
- **WebAuthn:** padrão web para autenticação forte com credenciais de chave pública.
- **Headless browser:** navegador automatizado sem interface visual.
- **Anti-tampering:** técnicas para detectar ou dificultar adulteração do software.
- **Telemetry:** dados técnicos sobre execução, falhas e comportamento do sistema.
