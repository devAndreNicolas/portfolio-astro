# ATS search strategy

This document is a durable operating note, not a dated list of search links. Generate fresh links with `pnpm jobs:searches`; it applies the rolling freshness window.

## InHire: search separately

InHire should not share the generic English-title query used by global ATS boards. Its Brazilian listings are commonly indexed under `carreira.inhire.com.br` and use Portuguese titles such as `Desenvolvedor(a) Full Stack`, `Pessoa Desenvolvedora`, or `Desenvolvedor(a) Frontend`.

The search configuration therefore uses four dedicated Portuguese query families:

- Full Stack: TypeScript, React, Angular, Node.js, or JavaScript.
- Frontend: TypeScript, Angular, or React.
- Software / Product: software-engineering and API terms.
- Applied AI: Portuguese and English AI terms plus TypeScript.

It intentionally does not require `Brazil`, `Brasil`, or a specific city in the Google query. Many valid InHire listings only state `remoto`, `100% remoto`, `híbrido`, or reveal location after opening the role. The collector still validates Brazilian relevance from the actual page before saving it.

## Operating rules

1. Treat Google `after:` as discovery freshness only, not publication date.
2. Open the official ATS page and verify that application is active before applying.
3. Do not treat a company career landing page as a vacancy; it is only a discovery lead.
4. Analyze a saved description before selecting a CV variant.
